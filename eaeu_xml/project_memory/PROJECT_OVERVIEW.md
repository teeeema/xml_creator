# Project overview

`eaeu_xml` — независимый Python 3.11+ универсальный движок технологических XML/SOAP-сообщений ЕАЭС.

Финальный нормативный аудит ядра завершён со статусом `DECISION_5_CORE_VERIFIED_WITH_UNRESOLVED_ITEMS`. APPLICATION, Integration, сигналы, SOAP Fault и шесть универсальных шаблонов транзакций сопоставлены с Решением №5, реестром и тестами. Конкретные процессы P.MM.01, структуры R.*, EDocHeader, GUI, БД и transport не входят в проект.

Нормативный источник находится непосредственно в корне автономного проекта: `./15kr0005.doc`. Старый код `xml_creator` не используется как архитектурная или нормативная основа.

Данные конкретных общих процессов находятся во внешних `ProcessPackage`, путь к которым явно передаётся вызывающим кодом. Движок не содержит P.MM.01, конкретных PRC/TRN/MSG/R.* или процессных XSD. Первый внешний каталог `P.MM.01/` создан как пустой source-first skeleton со статусом `NEEDS_NORMATIVE_SOURCES`.
