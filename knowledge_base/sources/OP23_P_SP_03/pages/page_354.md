(ipcdo:ApellationOfOriginRegisterItemDetails), в первом 
из таких экземпляров реквизита «Сведения записи Единого реестра 
НМПТ Союза» (ipcdo:ApellationOfOriginRegisterItemDetails) значение 
реквизита «Код вида записи общего информационного ресурса» 
(ipsdo:ResourceItemKindCode) должно соответствовать значению 
«AO» – «сведения о НМПТ Союза», во втором из таких экземпляров

(ipcdo:ApellationOfOriginRegisterItemDetails) значение реквизита 
«Код вида записи общего информационного ресурса» 
(ipsdo:ResourceItemKindCode) должно соответствовать значению 
«RH» – «сведения о праве использования НМПТ Союза»

экземпляр реквизита «Сведения записи Единого реестра НМПТ Союза» 
(ipcdo:ApellationOfOriginRegisterItemDetails), в его составе значение
