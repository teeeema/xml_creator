Требования к заполнению реквизитов электронных документов

Код требования Формулировка требования 
 
1 
 
в электронном сообщении должен присутствовать только один экземпляр 
реквизита «Сведения из отчета о зачислении и распределении сумм ввозных 
таможенных пошлин» (ds01cdo:ChargedDistributedDutyReportDetails) 
 
2 
 
в сложном реквизите «Сведения из отчета о зачислении и распределении 
сумм ввозных таможенных пошлин» 
(ds01cdo:ChargedDistributedDutyReportDetails) должен присутствовать только 
один экземпляр реквизита «Информация о суммах зачисленных и 
распределенных ввозных таможенных пошлин» 
(ds01cdo:ChargedDistributedDutyDetails), имеющий реквизит «Признак 
ежедневных сведений» (ds01sdo:DailyInfoIndicator) со значением «1» для 
передачи сведений за отчетный день 
 
3 
 
в сложном реквизите «Сведения из отчета о зачислении и распределении 
сумм ввозных таможенных пошлин» 
(ds01cdo:ChargedDistributedDutyReportDetails) должен отсутствовать 
экземпляр реквизита «Информация о суммах зачисленных и распределенных 
ввозных таможенных пошлин» (ds01cdo: ChargedDistributedDutyDetails), 
имеющий реквизит «Признак ежедневных сведений» 
(ds01sdo:DailyInfoIndicator) со значением «0» для передачи сведений за 
отчетный месяц нарастающим итогом 
 
4 
 
для реквизита «Сведения из отчета о зачислении и распределении сумм 
ввозных таможенных пошлин» 
(ds01cdo:ChargedDistributedDutyReportDetails) значение реквизита «Дата 
отчета» (csdo:EventDate) должно содержать дату рабочего дня, следующего 
за датой, указанной в реквизите «Дата предыдущего отчета» 
(ds01sdo:PreviousReportDate)
