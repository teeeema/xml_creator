## Application Action URI format

CONFIRMED_PDF: Decision №5 defines `wsa:Action` for common-process application messages as `int://` + `CP` + process code + process version + procedure code + transaction code + message code, separated by `/`. This corresponds to `int://CP/PROCESS/VERSION/PRC/TRN/MSG`.

Evidence pages: [[sources/DECISION_5/pages/page_014]].

## Logical address format

CONFIRMED_PDF: logical participant addresses use the fixed `EAEU://` prefix; exact address components must follow the Decision №5 rules and process-specific participant data.
