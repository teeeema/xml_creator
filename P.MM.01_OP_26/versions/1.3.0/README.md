## Почему необходим отдельный пакет

Текущий `ProcessPackageLoader.load()` загружает PRC, OPR, TRN, MSG и правила из единственного каталога, а `version_profiles/*.yaml` переключает только версии структур и моделей. Простое изменение `process_version` не даёт независимого нормативного профиля. Разработка полноценного независимого пакета должна сохранять отдельные manifests, структуры, правила, политики и тесты, а выбор версии — требовать явного запроса и проверок готовности.
