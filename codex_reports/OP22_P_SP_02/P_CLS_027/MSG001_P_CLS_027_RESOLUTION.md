# MSG.001 — P.CLS.027 resolution

## Нормативный случай

`P.SP.02.MSG.001`, таблица 34, REQ.4/REQ.5 требует проверить наличие вида документа
«Заявка на регистрацию товарного знака, знака обслуживания Евразийского экономического союза»
в P.CLS.027.

В актуальном классификаторе по Решению №92 (стр. 10), с происхождением изменения по Решению №148 (стр. 2),
есть точное значение `07220` с тем же наименованием.

Следовательно активна ветвь REQ.4:

- `ipcdo:TrademarkApplicationDetails/ipsdo:IPDocKindCode` = `07220`;
- `ipcdo:TrademarkApplicationDetails/ipsdo:IPDocKindName` — `FORBIDDEN`;
- fallback REQ.5 для отсутствующего классификаторного значения к этому виду документа не применяется.

GUI-правило: «Код вида документа заполняется значением 07220 в соответствии с классификатором видов документов по Решению №92.»
