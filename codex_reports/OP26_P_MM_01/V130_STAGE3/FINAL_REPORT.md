## ROOT_CAUSE и реализация

Компилятор этапа 2 распознавал ограниченную грамматику. Проверка союзов внутри исходного текста ошибочно захватывала названия полей («Начальная дата и время»), не учитывались генитив «экземпляр реквизита», ряд условных и parent-qualified конструкций. Добавлена закрытая offline grammar: сначала выделяются буквальные QName references, затем сопоставляется полное предложение. Неоднозначная привязка и нераспознанные части остаются deferred; runtime NLP и message-specific if в движке не появились.

Добавлены/расширены REQUIRED, FORBIDDEN, CARDINALITY (включая 0..1), FIXED, ENUM, AT_LEAST_ONE, условные predicates, UNIQUE кодов стран и POSITIONAL_VALUES ролей государств. Текущий состав: 132 REQUIRED, 105 FORBIDDEN, 25 CARDINALITY, 78 FIXED, 54 CLASSIFIER, 42 ENUM, 76 AT_LEAST_ONE, 3 POSITIONAL_VALUES, 3 UNIQUE. Диапазоны MSG.002/MSG.035 сохраняют источники обоих контекстов; перед expansion проверяются полнота диапазона и отсутствие дубликатов.

Обнаружен и воспроизведён общий дефект cardinality: отсутствующий None list slot считался узлом, хотя сериализатор его пропускал. Подсчёт узлов согласован с сериализацией; пустые списки не считаются заполнением запрещённого поля, explicit empty element остаётся отличимым от отсутствия. При завершении воспроизведён конфликт semantics is_complete: параллельная работа меняла смысл флага между полнотой rules и полнотой XML. Тесты не ослаблены; несогласованность сохранена в результатах неуспешного прогона. Нормативная готовность определяется отдельно по источникам, unresolved diagnostics, STRICT и readiness gate, а не одним флагом.

Каждый из 518 predicates проверяется positive и negative XML mutation test через существующий StructuredProcessBodyProvider → StructuredRuleEvaluator. Сохранены actual XML/diagnostics/hash для всех 41 MSG. Этот TEST компонентный путь не активирует draft package и не доказывает полный application PRC/TRN/MSG/transport/correlation E2E.

## Официальные данные классификаторов

Обнаружен рабочий public NSI API, используемый официальным SPA. Системный curl с обычной TLS-проверкой получил данные, несмотря на ошибку цепочки сертификатов Python urllib. Неуспех одного клиента не объявлен недоступностью всего сервиса.

Для 22 явно напечатанных в нормативном каталоге NSI codes получены опубликованные паспорта. Для 8 наборов проверены server total, все страницы, unique record IDs, actual status и literal data.Code. Получены 2021, 1041, 1016, 2044, 2045, 1019, 2046, 1030. Raw responses, URLs, method/request, versionId/effective dates и SHA-256 сохранены в `sources/nsi_acquisition.json` и `sources/nsi/`. Дата снимков — **23.10.2026**, а не автоматическая актуальность на любую последующую дату.

Offline indexes загружаются canonical loader; Rule Engine использует реальную membership-проверку. Неверный код отклоняется, отсутствие набора возвращает non-PASS external reference. Raw authorityStatus=notAvailable сохранён без придуманного толкования; publication_status=published и actual payload проверены отдельно. Индексы не содержат подставленного тестового классификатора.

Ещё 4 набора имеют custom/multiple code columns и не привязаны по догадке; 10 data endpoints вернули ошибки при доступном паспорте; для 25 ссылок нет явно указанного NSI binding. Поэтому 39 lookup dependencies остаются незакрытыми. Наличие snapshot не означает завершения всех требований с этим классификатором: 22 source rows ещё требуют реализации/уточнения соответствующей привязки. Поправка 77 по P.MM.01.CLS.009/.010 и .028/.029 сохранена и проверена.

`GAP_REGISTER.csv`: 851 контекстная запись — 591 QName rows + 211 requirement rows + 39 classifiers + 7 XSD closures + history + E2E + общая регрессия. Это не число независимых нормативных атомов. Одна отсутствующая модельная зависимость блокирует много строк.
